# Data

**Status:** Draft. Decisions: D41, D52–D55. Columns are written in build mode; this doc fixes where data lives, its keys, and retention.

## Stores

| Store | Holds | Hot path waits on it? |
|---|---|---|
| Postgres | Users, wallets, follows, orders + firings, nonce ledger, positions, token metadata, trailing highs | No: engine/execution cache in memory, write in background |
| ClickHouse | Swaps, pool events, candles, backfill, routing logs, execution outcomes | No |
| Kafka | All engine and execution output | No (publish is async) |
| Object storage | Engine snapshots; archived input log (D54): `inputs/<chain>/<core instance>/<first seq>.pb` segments of length-delimited `InputRecord`s, bucket `omnimarket-inputs` in dev; write-once audit log copy (D55) | No |

## ClickHouse and reorgs

- Key: (chain, block hash, log index). Re-inserts are harmless → restartable backfills (D15).
- Status per row: provisional → confirmed → final, or removed. Versioned inserts; `ReplacingMergeTree` keeps the latest.
- Candles: built live from `swaps.<chain>` by the candle service; rebuilt for windows touched by corrections. 1s candles are also a recovery input (D39).

Protobuf; schemas live in `proto/` and are checked for compatibility in CI (`scripts/proto-check.sh`: `buf lint`, and `buf breaking` against `main`, D70). Rust types are generated by the `proto` crate (prost, compiled with protox, so no `protoc` is needed).

## Records and lineage IDs (D71)

Every wide event carries `omnimarket.lineage.v1.Lineage { id, caused_by[] }`, with 16-byte IDs. A record with a natural key takes `LineageId::from_natural_key(kind, key)`: BLAKE3 over the kind (length-prefixed) and the key fields, fixed-width little-endian in the order listed, cut to 128 bits. A record without one takes two draws from the core's seeded Rng, so replay reproduces it.

| Record | Schema | Kind | Natural key | Caused by |
|---|---|---|---|---|
| Input-log record | `omnimarket.det.v1.InputRecord` | (none: an input, not a wide event) | (core instance, seq) | |
| Toy swap (M0 demo) | `omnimarket.sim.v1.ToyEvent` | `sim.toy_event` | id (u64) | |
| Toy quote (M0 demo) | `omnimarket.sim.v1.Quote` | | none: seeded Rng | |
| Toy decision (M0 demo) | `omnimarket.sim.v1.ToyDecision` | `sim.toy_decision` | event id (u64) | the swap, then the quote |
| Chain event | `omnimarket.chain.v1.Log` (inside `Block`) | `chain_event` | chain id (u64), block hash (32 bytes), log index (u64) | |
| Pool update | `omnimarket.pool.v1.PoolUpdate` | `pool_update` | chain id (u64), pool (20 bytes), block hash (32 bytes), log index (u64) | the chain event |

Chain events will key on (chain, block hash, log index), firings on the firing ID (D35) and intents on their hash, as each schema lands.

## Observability data (D53–D55)

- **Lineage edges** (cause ID → effect ID, with type and timestamp) in ClickHouse; money paths 100%.
- **Decision records** (alternatives, scores, reasons, config version, brake state) in ClickHouse, 1 year.
- **Audit log:** hash-chained, append-only, ClickHouse + write-once Cloud Storage; daily root anchored on Base. Kept forever.

## Privacy (D52)

Telemetry uses pseudonymous user IDs. Per-user records are encrypted with a per-user key; deleting the key makes them unreadable (crypto-shredding) while the audit log's hash chain stays verifiable.

## Snapshots

Versioned, compressed binary per chain every ~30s (D40); last 10 kept. RustFS in dev/staging (D75); Cloud Storage in production (D51).

## Retention

Candles forever. Raw swaps from the 30-day backfill onward; downsample past 90 days if needed.
